# States and Callouts

> [!abstract] Summary
> A compact summary state.

> [!info] Information
> Informational content uses signal cyan.

> [!tip] Tip
> Helpful content remains distinct from success.

> [!success] Success
> Completed work uses field olive.

> [!question] Question
> Questions use the archive stamp color.

> [!warning] Warning
> Warnings include text, icon, border, and color.

> [!failure] Failure
> Failure uses oxblood.

> [!danger] Danger
> Critical content uses the strongest semantic treatment.

> [!bug] Bug
> Bug reports remain readable in long paragraphs.

> [!quote] Quote
> A neutral quotation treatment.

## Task states

- [ ] Unchecked task
- [x] Checked task
- [/] In-progress task
- [-] Cancelled task
- [!] Important task
