## Long-form reading sample

A useful theme must survive ordinary work, not only a polished screenshot. This paragraph is intentionally long enough to reveal line length, line height, paragraph rhythm, font fallback, and the relationship between the editor surface and the louder application chrome. Archive Olive should retain a measured reading column while tables, media, and data views are allowed to use the space they genuinely need.

The second paragraph checks the rag and density. Field manuals are compact because they are built for retrieval, but compactness must not collapse into crowding. Metadata should be scannable, headings should create reliable landmarks, and sidebars should distinguish current context without becoming permanent advertisements for the palette.
