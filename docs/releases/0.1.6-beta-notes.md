# Archive Olive 0.1.6 Beta

Archive Olive `0.1.6` refines the native Obsidian file explorer into a clearer
editorial hierarchy without changing folder names, paths, sorting, or tree
interaction.

## Added

- Generated two-digit sequence markers for top-level folders. The numbers
  follow the current visual order and never become part of folder names.
- Distinct visual roles for top-level folders, nested folders, and files.
- A shared trailing `+`/`−` disclosure axis for collapsed and expanded folders.
- Regression checks and isolated desktop runtime evidence for file-tree
  alignment, active state, truncation, and overflow.

## Changed

- File and folder row surfaces now use the full file-list width.
- The leading disclosure gutter and persistent vertical guide rails are
  removed, leaving more room for names.
- Same-depth file text aligns with the first visible marker of sibling folders.
- The active file keeps its natural row height and uses only a paper or recessed
  surface plus stronger text weight.

## Removed

- Cyan active and hover markers from file rows.
- The oversized detached-card treatment from the active file.

## Compatibility and validation

- Current tested baseline: Obsidian Desktop `1.12.7` on macOS.
- Runtime acceptance used only the repository's isolated `test-vault/`.
- Light and dark desktop screenshots, full-width geometry, long-name
  truncation, disclosure hit areas, and horizontal overflow were checked.
- Mobile keeps the existing `44px` touch-row contract, but real-device iPhone
  and iPad file-explorer acceptance remains pending.
- Large-vault virtualized scrolling remains a known review item because CSS
  counters may restart when distant rows are virtualized.

GitHub Raw caching can delay a BRAT update by several minutes.

### Key decisions

- Keep the implementation CSS-only and preserve Obsidian's native tree model.
- Generate visual order independently from folder names and paths.
- Publish the desktop-validated hierarchy without claiming pending mobile or
  large-vault acceptance.
- Ship an immutable patch checkpoint rather than alter the published `0.1.5`
  tag.

### Verification evidence

- Local repository validation, CSS parsing, formatting, design lint, and
  release-policy checks pass.
- Obsidian Desktop `1.12.7` acceptance used only the isolated repository
  `test-vault/`.

### Open questions / risks

- Real-device iPhone and iPad file-explorer acceptance remains pending.
- Large-vault virtualized scrolling may reset presentation-only root counters.
- GitHub Raw caching may delay patch delivery.
