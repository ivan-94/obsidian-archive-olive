## Scope

This patch adds optional independent light and dark colorways, preserves the
existing plugin-free defaults, standardizes every dark Markdown body on pure
black, and simplifies persistent desktop and iPad workspace dividers. It does
not claim the pending cross-platform colorway matrix as passed.

## Publication commands

```sh
git fetch origin
test "$(git rev-parse HEAD)" = "<approved-commit>"
git tag -a 0.1.5 <approved-commit> -m "Archive Olive 0.1.5 beta"
git push origin 0.1.5
gh release create 0.1.5 \
  theme.css \
  manifest.json \
  LICENSE \
  assets/screenshots/archive-olive-512x288.png \
  --repo ivan-94/obsidian-archive-olive \
  --verify-tag \
  --prerelease \
  --title "Archive Olive 0.1.5 Beta" \
  --notes-file docs/releases/0.1.5-beta-notes.md
```

## Rollback

BRAT follows `main`. If the patch regresses another state, restore the `0.1.4`
behavior through a new commit that changes `theme.css`; do not move either
published tag.
