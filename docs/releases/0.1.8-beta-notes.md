# Archive Olive 0.1.8 Beta

Archive Olive `0.1.8` repairs the settings surfaces that were still being
overridden by Obsidian's platform-specific controls, while preserving Signal
White and the existing beta channel.

## Fixed

- Active Signal White mobile navigation now uses the configured control accent
  and a matching foreground for labels and icons.
- The iPad drawer now has one complete border and no native bottom fade, while
  settings modals retain their normal stacking order.
- Settings search, buttons, close controls, and section headings no longer
  combine rounded platform decoration with the theme's square geometry.
- Desktop settings explicitly override macOS's late pill-radius tokens and
  suppress offset button shadows in that surface.

## Compatibility and validation

- Compatibility floor remains Obsidian Desktop `1.12.7`.
- Runtime diagnosis used only the repository's isolated `test-vault/`.
- `node scripts/validate.mjs --release`, CSS parsing, formatting, and diff
  checks pass for the release candidate.
- Owner-led final visual acceptance on iPad and desktop remains in progress.

GitHub Raw caching can delay a BRAT update by several minutes.
