# Archive Olive 0.1.7 Beta

Archive Olive `0.1.7` adds Signal White, a brighter light colorway inspired by
white editorial workspaces with black structural rules and restrained signal
colors.

## Added

- Signal White as the fifth light colorway in the optional Style Settings
  selector.
- Pure-white note and root-pane surfaces with a warm-white sidebar.
- Signal-yellow ribbon and active root tabs.
- A pink active-file surface that remains visually separate from semantic
  success, warning, and information colors.

## Changed

- Light-mode chrome, active tabs, controls, ribbon actions, and file selection
  now consume dedicated semantic tokens.
- Existing Archive Olive, Blueprint News, Terracotta Ledger, and Forestry File
  values and the plugin-free defaults remain unchanged.

## Compatibility and validation

- Current tested baseline: Obsidian Desktop `1.12.7` on macOS.
- Runtime acceptance used only the repository's isolated `test-vault/`.
- All 96 colorway-specific contrast pairs meet WCAG AA.
- A Chromium cascade matrix passes all 20 light/dark selector combinations.
- Every dark colorway retains its pure-black Markdown editing and reading
  surface.
- Real-device and cross-platform review of Signal White remains pending.

GitHub Raw caching can delay a BRAT update by several minutes.
