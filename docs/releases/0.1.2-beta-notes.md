# Archive Olive 0.1.2 Beta

Archive Olive `0.1.2` completes the interaction-state accessibility repair started in `0.1.1`.

## Fixed

- Navigation and tab-list controls remain visible on the carbon title bar after pane blur, window blur, hover, press, and menu-open transitions.
- Active side-dock controls keep a field-olive surface and cyan bottom rule, so the selected tool remains distinct from other readable controls.
- Markdown table headers keep carbon-and-paper contrast while Obsidian activates column handles or its inline table editor.
- Light and dark modes now have regression coverage for title-bar controls, selected side-dock controls, and interactive table headers.

The patch does not change the palette, layout, compatibility floor, or BRAT channel.

## Install or update with BRAT

1. Install and enable the BRAT community plugin.
2. Open **Settings → BRAT**.
3. Add `https://github.com/ivan-94/obsidian-archive-olive` as a beta theme, or update the existing registration.
4. Select **Archive Olive** under **Settings → Appearance → Themes**.
5. Reload Obsidian once.

GitHub Raw caching can delay a BRAT update by several minutes.

## Compatibility and validation

- Current tested baseline: Obsidian Desktop `1.12.7` on macOS.
- The reported states were reproduced in the real `test-vault` workspace.
- Computed-style checks covered side-dock pane blur, menu-open tab-list controls, selected side-dock identity, and interactive Markdown table headers.
- Twenty normative light and dark contrast pairs pass the repository release gate.
- Real Windows, Linux, iOS, and Android acceptance remains pending.

### Key decisions

- Bind control contrast to the chrome surface instead of window or pane focus.
- Give selected side-dock controls a persistent color block and geometric state cue.
- Preserve the table-header surface through Obsidian's live table-editor DOM.
- Publish a new patch instead of replacing the immutable `0.1.1` tag or assets.

### Verification evidence

- The real Obsidian runtime reports field olive, cyan, and paper for the selected side-dock state.
- All four visible Markdown table headers report carbon backgrounds and paper foregrounds while the active column handle is present.
- Static release validation, CSS parsing, formatting, and twenty contrast checks pass locally.
