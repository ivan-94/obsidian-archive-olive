## Scope

This patch promotes the approved CSS-only file-explorer hierarchy: generated
root sequence markers, distinct root-folder/nested-folder/file roles, trailing
disclosure controls, full-width rows, aligned content markers, and a
natural-height active file. It does not claim pending real-device mobile or
large-vault virtual-scroll acceptance.

## Publication commands

```sh
git fetch origin
test "$(git rev-parse HEAD)" = "<approved-commit>"
git tag -a 0.1.6 <approved-commit> -m "Archive Olive 0.1.6 beta"
git push origin 0.1.6
gh release create 0.1.6 \
  theme.css \
  manifest.json \
  LICENSE \
  assets/screenshots/archive-olive-512x288.png \
  --repo ivan-94/obsidian-archive-olive \
  --verify-tag \
  --prerelease \
  --title "Archive Olive 0.1.6 Beta" \
  --notes-file docs/releases/0.1.6-beta-notes.md
```

## Rollback

BRAT follows `main`. If the patch regresses another state, restore the `0.1.5`
behavior through a new commit that changes `theme.css`; do not move either
published tag.
