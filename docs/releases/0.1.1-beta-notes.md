# Archive Olive 0.1.1 Beta

Archive Olive `0.1.1` is a focused accessibility patch for application-chrome contrast.

## Fixed

- Navigation and tab-list icons remain visible on the carbon title bar.
- Inactive root tabs use high-contrast khaki instead of graphite in light mode.
- Inactive side-dock tabs and controls use carbon on signal cyan.
- The vault-switcher chevron inherits the readable foreground of its olive profile block.
- Light and dark modes now share explicit semantic tokens for chrome, accent, and selected-control foregrounds.

The patch does not change the palette, layout, compatibility floor, or BRAT channel.

## Install or update with BRAT

1. Install and enable the BRAT community plugin.
2. Open **Settings → BRAT**.
3. Add `https://github.com/ivan-94/obsidian-archive-olive` as a beta theme, or update the existing registration.
4. Select **Archive Olive** under **Settings → Appearance → Themes**.
5. Reload Obsidian once.

GitHub Raw caching can delay a BRAT update by several minutes.

## Compatibility and validation

- Current tested baseline: Obsidian Desktop `1.12.7` on macOS.
- The reported states were reproduced from BRAT-installed `0.1.0` screenshots.
- The repair was checked in the real three-pane Obsidian workspace in both light and dark appearances.
- Six new contrast regression pairs cover inactive chrome, side-dock icons, and vault-switcher controls.
- Real Windows, Linux, iOS, and Android acceptance remains pending.

### Key decisions

- Treat the issue as a semantic foreground/surface mismatch, not as a palette or opacity tweak.
- Keep the patch limited to application chrome and preserve all layout behavior.
- Use a new patch version instead of replacing the published `0.1.0` assets.

### Verification evidence

- Light and dark real-application checks pass on Obsidian Desktop `1.12.7`.
- Static validation covers sixteen normative contrast pairs after the patch.
