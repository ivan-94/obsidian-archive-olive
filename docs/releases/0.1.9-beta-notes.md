# Archive Olive 0.1.9 Beta Tag

Archive Olive `0.1.9` simplifies the button language across the theme.

## Fixed

- Standard buttons now use a 1px border instead of the previous heavyweight
  rim.
- Removed offset button shadows and press displacement globally.
- Matched hover treatment to the light control style used by select fields.

## Compatibility and validation

- Compatibility floor remains Obsidian Desktop `1.12.7`.
- `node scripts/validate.mjs --release`, CSS parsing, formatting, and diff
  checks pass for this local candidate.
- The annotated `0.1.9` tag is pushed. No GitHub pre-release has been created.

GitHub Raw caching can delay a BRAT update by several minutes after a future
publication.
