# Archive Olive 0.1.3 Beta

Archive Olive `0.1.3` is a mobile visual-hardening patch prepared from a real-iPhone audit while preserving the accepted desktop appearance.

## Fixed

- Dark mobile menus, drawer selectors, search prompts, settings navigation, and form fields now use explicit high-contrast semantic surfaces instead of Obsidian's low-contrast mobile interactive remapping.
- Mobile tap, active, selected, label, and disabled states remain distinguishable in both light and dark modes.
- Search prompts, inputs, and result surfaces are opaque, preventing note content from showing through.
- Non-semantic mobile pill geometry is removed while 44 px touch targets and iOS safe-area behavior remain intact.
- Tooltips and notices use explicit high-contrast foreground and background pairs.
- Side-dock icon strips hide the WebKit scrollbar without disabling horizontal overflow.
- Context-menu hover and selected states keep readable inherited foregrounds.

The patch keeps the palette, desktop layout, compatibility floor, and BRAT channel unchanged.

## Install or update with BRAT

1. Install and enable the BRAT community plugin.
2. Open **Settings → BRAT**.
3. Add `https://github.com/ivan-94/obsidian-archive-olive` as a beta theme, or update the existing registration.
4. Select **Archive Olive** under **Settings → Appearance → Themes**.
5. Reload Obsidian once.

GitHub Raw caching can delay a BRAT update by several minutes.

## Compatibility and validation

- Current tested desktop baseline: Obsidian Desktop `1.12.7` on macOS.
- A real iPhone and Safari Web Inspector were used to audit the pre-fix mobile states.
- Static release validation covers 28 light/dark desktop, menu, feedback, mobile, and table-header contrast pairs.
- Mobile semantic tokens are statically required to remain inside `.is-mobile` scope.
- Desktop light, dark, and blurred-window regression checks pass in the isolated repository `test-vault`.
- Owner-led verification of this published candidate on a real iPhone remains pending; this beta does not claim final iOS acceptance.
- Windows, Linux, and Android acceptance also remains pending.

### Key decisions

- Keep all new mobile semantic tokens and component rules inside `.is-mobile` scope.
- Preserve the accepted desktop palette, layout, and interaction styling.
- Publish an immutable patch checkpoint for owner-led BRAT and iPhone acceptance without claiming the pending real-device retest has passed.

### Verification evidence

- The repository release gate, CSS parser, formatter, and 28 contrast checks pass locally.
- Desktop light, dark, and blurred-window screenshots show no visual regression.
- Desktop computed styles do not receive `--ao-mobile-*` tokens.
- Six pre-fix real-iPhone audit screenshots were reviewed locally; because they contain real vault context, they remain untracked under the local audit directory in accordance with the repository privacy policy.
