# Archive Olive 0.1.0 Beta

Archive Olive `0.1.0` is the first beta checkpoint of a practical brutalist Obsidian theme.

The theme combines archival khaki, field olive, oxblood, signal cyan, carbon rules, condensed headings, and square controls while keeping long-form writing calm and readable. Both light and dark appearances are included.

## Install with BRAT

1. Install and enable the BRAT community plugin.
2. Open **Settings → BRAT → Add Beta Theme**.
3. Enter `https://github.com/ivan-94/obsidian-archive-olive`.
4. Select **Archive Olive** under **Settings → Appearance → Themes**.

## Included

- Workspace shell, sidebars, tabs, editor, Reading View, properties, backlinks, menus, dialogs, and notices.
- Markdown headings, lists, tasks, quotes, callouts, code, tables, links, tags, and embeds.
- Graph, Canvas, and Bases styling.
- Keyboard focus, selected, disabled, error, and empty states.
- Narrow-window and mobile-aware styling.
- MIT-licensed source, automated validation, issue forms, and public acceptance documentation.

## Compatibility and validation

- Current tested baseline: Obsidian Desktop `1.12.7` on macOS.
- BRAT `2.2.0` clean-vault install, changed stylesheet delivery, activation, disable, unregister, and removal pass.
- Automated repository, CSS, token, contrast, formatting, and packaging checks pass.
- Owner-led visual acceptance through the published BRAT artifact is scheduled after this pre-release.
- Windows, Linux, iOS, and Android real-device acceptance is not yet claimed.

## Known limitations

- GitHub Raw caching can delay BRAT updates. Wait several minutes and retry before removing and re-adding the repository.
- This is an opt-in beta checkpoint and has not completed its post-release private pilot.
- Optional texture, Style Settings integration, curated community-plugin rules, and Obsidian Publish support are outside `0.1.0`.
- Cross-platform typography can differ because the theme uses system/local fallback fonts.
