# Archive Olive 0.1.5 Beta

Archive Olive `0.1.5` adds optional colorways while preserving the existing
Archive Olive and Archive Night defaults. Light and dark choices are stored
independently through the optional Style Settings community plugin.

## Added

- Four light colorways: Archive Olive, Blueprint News, Terracotta Ledger, and
  Forestry File.
- Four dark colorways: Archive Night, Carbon Teal, Oxblood Archive, and Midnight
  Blueprint.
- Complete colorway-specific surface ramps, semantic feedback colors, syntax
  colors, graph colors, mobile inputs, hover states, and RGB aliases.
- Automated validation for the Style Settings contract, token completeness,
  light/dark independence, and 72 colorway contrast pairs.

## Changed

- Every dark colorway now keeps the Markdown editing and reading surface pure
  black while retaining its selected palette in the surrounding workspace.
- Persistent desktop and iPad workspace divider lines are simplified while
  resize affordances remain visible on hover and iPhone chrome remains
  unchanged.

Style Settings is optional. Without it, Archive Olive and Archive Night continue
to work exactly as the built-in defaults.

## Install or update with BRAT

1. Install and enable the BRAT community plugin.
2. Open **Settings → BRAT**.
3. Add `https://github.com/ivan-94/obsidian-archive-olive` as a beta theme, or
   update the existing registration.
4. Select **Archive Olive** under **Settings → Appearance → Themes**.
5. To use alternate palettes, install Style Settings and open
   **Settings → Style Settings → Archive Olive**.

GitHub Raw caching can delay a BRAT update by several minutes.

## Compatibility and validation

- Current tested baseline: Obsidian Desktop `1.12.7` on macOS.
- Style Settings runtime parsing and representative light/dark switching were
  checked only in the isolated repository `test-vault/`.
- Seventy-two colorway-specific contrast pairs meet WCAG AA; the lowest passing
  ratio is `4.55:1`.
- A Chromium cascade matrix passes all 16 combinations of light and dark
  selector classes.
- Broader mobile, Windows, Linux, and Android colorway review remains pending.

### Key decisions

- Keep the existing palettes as plugin-free defaults.
- Use one optional Style Settings selector per appearance mode.
- Keep every dark Markdown body pure black and confine colorway identity to the
  surrounding workspace and semantic accents.
- Publish an immutable patch checkpoint without claiming pending cross-platform
  colorway acceptance.

### Verification evidence

- Local release validation, CSS parsing, formatting, design lint, and contrast
  checks pass.
- Obsidian Desktop acceptance used only the isolated repository `test-vault/`.

  review.
