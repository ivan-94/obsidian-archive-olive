# Archive Olive 0.1.4 Beta

Archive Olive `0.1.4` is an iOS visual follow-up based on real iPad and iPhone review. It stabilizes drawer navigation and gives dark Markdown content a pure-black surface while keeping the surrounding olive-black application chrome.

## Fixed

- Dark Markdown editing and reading surfaces now use pure black on desktop, iPhone, and iPad.
- The iPad drawer no longer reserves an empty ribbon gutter when the ribbon is hidden.
- The iPad drawer selector stays at a stable 52 px height when its menu opens.
- The expanded drawer option list now starts below the active selector, keeping the frame and the first “File explorer” option visible after switching views.
- Redundant iOS drawer dividers and the iPhone view-header line are removed.
- Light iPad safe-area chrome, sidebar controls, and mobile callout labels remain readable.
- Paired iPad drawers and tablet selection states remain square and non-overlapping.
- Mobile metadata, toolbar layers, prompts, search fields, and form controls preserve the theme's hard-edged geometry without covering adjacent content.

The patch keeps the compatibility floor and BRAT channel unchanged.

## Install or update with BRAT

1. Install and enable the BRAT community plugin.
2. Open **Settings → BRAT**.
3. Add `https://github.com/ivan-94/obsidian-archive-olive` as a beta theme, or update the existing registration.
4. Select **Archive Olive** under **Settings → Appearance → Themes**.
5. Reload Obsidian once.

GitHub Raw caching can delay a BRAT update by several minutes.

## Compatibility and validation

- Current tested desktop baseline: Obsidian Desktop `1.12.7` on macOS.
- Real-device verification used the isolated repository `test-vault/` on an iPad running iPadOS `27.0`.
- Safari Web Inspector verified a `744 × 1133` CSS-pixel viewport at DPR `2`, pure-black Markdown content, a stable 52 px selector, and a visible non-overlapping option list.
- Static release validation covers 30 light/dark desktop, menu, feedback, mobile, and table-header contrast pairs.
- Mobile semantic tokens remain inside `.is-mobile` scope; the pure-black Markdown surface intentionally applies to desktop and mobile dark mode.
- Final owner-led verification of the published candidate on a real iPhone remains pending.
- Windows, Linux, and Android acceptance also remains pending.

### Key decisions

- Keep the application chrome olive-black while making only dark Markdown content pure black.
- Share iOS visual corrections where iPhone and iPad use the same component, with tablet-only geometry rules where their layouts differ.
- Publish an immutable patch checkpoint without claiming the pending final iPhone retest has passed.
