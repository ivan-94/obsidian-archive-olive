This patch ships the mobile visual-hardening candidate produced from the real-iPhone audit, plus tooltip, notice, side-dock scrollbar, and context-menu readability fixes. It preserves the accepted desktop appearance and does not claim the pending repair-after iPhone matrix as passed.

## Publication commands

```sh
git fetch origin
test "$(git rev-parse HEAD)" = "<approved-commit>"
git diff --quiet -- theme.css manifest.json LICENSE assets/screenshots/archive-olive-512x288.png docs/releases/0.1.3-beta-notes.md
git tag -a 0.1.3 <approved-commit> -m "Archive Olive 0.1.3 beta"
git push origin 0.1.3
gh release create 0.1.3 \
  theme.css \
  manifest.json \
  LICENSE \
  assets/screenshots/archive-olive-512x288.png \
  --repo ivan-94/obsidian-archive-olive \
  --verify-tag \
  --prerelease \
  --title "Archive Olive 0.1.3 Beta" \
  --notes-file docs/releases/0.1.3-beta-notes.md
```
