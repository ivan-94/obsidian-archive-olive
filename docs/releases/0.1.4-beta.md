## Publication commands

```sh

test "$(git rev-parse HEAD)" = "<approved-commit>"
git diff --quiet -- theme.css manifest.json LICENSE assets/screenshots/archive-olive-512x288.png docs/releases/0.1.4-beta-notes.md
git tag -a 0.1.4 <approved-commit> -m "Archive Olive 0.1.4 beta"

  LICENSE \

  --prerelease \
  --title "Archive Olive 0.1.4 Beta" \
```
