## Scope

This patch makes the standard button treatment global: buttons now use a
single 1px border, no offset shadow, and no press displacement. Hover states
retain the same lightweight treatment. The change replaces the earlier
Pages-Publish-only adjustment so native and community-plugin buttons follow
one control language.
